02계정

사무국 계정 (2개)

전체 예약·참가신청을 보고, 검색·필터·엑셀 내려받기·대신 취소·첨부 소개서 열람이 가능합니다. 자격증명은 운영계정 엑셀 파일(JGCF2026-운영계정.xlsx)의 "사무국 계정" 시트에 있습니다.

상담기관 계정 (20개)

기관마다 하나씩, 기관아이디@2026jejugcf.com 형식입니다. 자기 기관에 매칭된 확정 예약만 보이고 읽기 전용입니다. 같은 엑셀의 "상담기관 계정" 시트에 있습니다.

각 기관에는 그 기관의 행만 전달하세요. 엑셀을 통째로 보내면 한 기관이 다른 19곳 계정으로 들어가 남의 신청 기업 연락처와 소개서를 볼 수 있습니다.

비밀번호를 잊었을 때

계정 도메인(2026jejugcf.com)이 아직 등록 전이라 비밀번호 재설정 메일이 가지 않습니다. 사무국이 직접 새 비밀번호를 지정해 전달합니다.

  1. Supabase 대시보드 → Authentication → Users
  2. 해당 계정 검색 → 우측 메뉴 → Reset password → 새 비밀번호 입력
  3. 담당자에게 전달하고 운영계정 엑셀도 갱신

03관리자 화면 사용법

/admin에서 사무국 계정으로 로그인하면 탭 4개가 보입니다. 처음 열리는 탭은 현황입니다.

탭내용할 수 있는 것
현황모집 상황 요약예약률(확정/280), 참가신청 구분별 수, 오늘 신규, 마감 D-day, 행사 당일 출석, 예약 없는 기관 수, 시간대별 점유 막대, 최근 7일 추이
밋업 예약전체 예약 (확정·취소 포함)상담기관·상태 필터(확정/취소/출석 완료/미도착), 검색(기업·담당자·연락처·번호), 소개서 PDF 열기, 건별 취소, 당일 출석 체크
행사 참가신청전체 참가신청검색(이름·소속·연락처·번호), 당일 출석 체크
기관별 현황상담기관 20곳 전체의 예약률·확정·취소·확정 시간대와 시간대 점유 격자(기관 × 시간)빈 기관·빈 시간대 파악, 격자 칸에 마우스를 올리면 신청 기업 표시, CSV

인쇄하기

각 탭 우측의 인쇄를 누르면 버튼·검색창 없이 표만 A4 가로로 나옵니다(머리글에 제목·건수·출력 시각). 상담기관은 자기 화면을 인쇄해 부스에 둘 수 있고, 사무국은 출석 명단이나 기관별 현황(2쪽은 시간대 격자)을 출력할 수 있습니다. 검색·필터를 건 상태 그대로 인쇄됩니다.

엑셀로 내려받기

각 탭 우측의 CSV 내려받기를 누르면 현재 보이는 목록(필터·검색 적용 상태)이 파일로 내려옵니다. 엑셀에서 바로 열리며 한글이 깨지지 않습니다.

행사 당일 출석 체크

가장 빠른 방법은 QR입니다. 신청자의 완료 화면(또는 예약 조회 화면)에 체크인 QR이 있습니다. 직원이 폰 기본 카메라로 찍으면 관리자 화면이 그 사람 행만 보이는 상태로 열리고, 출석 버튼만 누르면 됩니다(처음 한 번만 로그인). 별도 앱은 필요 없습니다.

QR이 없으면 관리자 화면에서 이름이나 연락처로 검색한 뒤 그 행의 출석 버튼을 누릅니다. 버튼이 초록색 "출석 ✓"로 바뀌고 시각이 기록됩니다. 잘못 눌렀으면 한 번 더 누르면 해제됩니다.

  • 밋업 예약 탭 상태 필터의 미도착을 고르면 확정인데 아직 안 온 사람만 남습니다 — 상담 시간 직전에 기관에 "아직 안 오셨다"고 알릴 때 씁니다.
  • 현황 탭의 행사 당일 출석 타일에서 밋업·참가 출석 인원이 실시간으로 집계됩니다.
  • 상담기관 화면에도 자기 예약 건의 출석 여부가 보여, 기관이 "다음 분 오셨는지" 스스로 확인할 수 있습니다(기관은 체크를 바꿀 수 없음).
  • CSV에 출석 여부·시각 열이 포함되므로 행사 후 출석률 보고에 그대로 쓸 수 있습니다.

예약을 대신 취소하기

신청자가 전화로 취소를 요청했거나 예약번호를 잃어버린 경우, 밋업 예약 탭에서 해당 행의 취소를 누르고 확인하면 됩니다. 취소 즉시 그 시간대가 다른 신청자에게 다시 열립니다. 취소 사유는 따로 기록되지 않으니 필요하면 별도 메모를 남기세요.

화면의 숫자는 새로고침을 눌러야 최신이 됩니다. 신청이 들어오는 중에 보고 있다면 한 번씩 눌러 주세요.

04상담기관이 보는 화면

기관 계정으로 같은 주소에 로그인하면 탭·필터·취소 버튼 없이 자기 기관의 확정 예약 목록만 시간순으로 보입니다. 항목은 상담시간·출석 여부(당일)·신청 기업·담당자·연락처·메일·상담 내용·소개서 PDF이며, 이것은 개인정보처리방침에 명시한 제3자 제공 범위와 같습니다.

  • 취소된 예약은 기관 화면에서 즉시 사라집니다 — 취소한 신청자의 정보는 더 이상 제공되지 않습니다
  • 기관은 예약을 취소하거나 수정할 수 없습니다 — 변경은 신청자 본인(마감 전) 또는 사무국만
  • 기관도 CSV 내려받기가 가능합니다 (자기 목록만)

07문제 상황 대응

신청자가 예약번호를 잃어버렸어요

관리자 화면 밋업 예약 탭에서 담당자 이름이나 연락처로 검색해 예약번호를 알려주세요. 본인 확인은 신청 시 입력한 연락처로 합니다.

신청자가 전화로 취소해 달래요

마감 전이면 본인이 /meetup/confirm에서 직접 취소할 수 있다고 안내하고, 어렵다고 하면 관리자 화면에서 대신 취소하세요. 마감 후에는 사무국만 취소할 수 있습니다.

"이미 예약하셨습니다" / "같은 시간에 이미 다른 상담이"라고 떠요

같은 담당자(메일 또는 연락처 기준)가 같은 기관을 또 예약하거나, 같은 시간에 다른 기관을 예약하려는 경우입니다. 다른 기관·다른 시간을 고르면 됩니다. 관리자 화면에서 그 연락처를 검색하면 기존 예약이 모두 보이고, 신청자 본인도 조회 화면에서 "같은 연락처의 다른 예약"으로 볼 수 있습니다. 한 담당자가 여러 기관을 예약하는 것은 허용됩니다.

원하는 시간이 마감이래요 / 방금 마감됐다고 떠요

그 기관·시간에 이미 확정 예약이 있는 겁니다. 시스템이 중복을 막은 것이니 정상입니다. 다른 시간이나 다른 기관을 안내하세요. 기관별 현황 탭에서 빈 시간대를 바로 확인할 수 있습니다.

마감 후에 예약을 바꿔 달래요

마감(9/15 자정) 후 신청자는 사이트에서 취소할 수 없습니다. 사무국이 관리자 화면에서 대신 취소할 수 있으나, 새 예약은 마감 후 누구도 만들 수 없습니다. 변경이 꼭 필요하면 해당 상담기관과 직접 조율해 주세요.

상담기관이 비밀번호를 잊었어요

02의 "비밀번호를 잊었을 때" 절차대로 Supabase 대시보드에서 새 비밀번호를 지정해 전달하세요. 재설정 메일은 가지 않습니다.

상담기관이 "내 화면에 예약이 안 보여요"라고 해요

기관 화면에는 확정 상태의 예약만 보입니다. 관리자 화면 밋업 예약 탭에서 그 기관으로 필터해 확정 건이 있는지 확인하세요. 신청자가 취소했으면 기관 화면에서 사라지는 게 맞습니다. 확정 건이 있는데도 안 보인다면 다른 기관 계정으로 로그인한 것일 수 있습니다 — 화면 상단의 기관명을 확인하세요.

사이트가 안 열려요

먼저 다른 기기나 네트워크에서도 같은지 확인하세요. 사무국 쪽 네트워크 문제인 경우가 많습니다. 사이트 자체 장애면 개발 담당에게 연락하세요. 이미 들어온 예약·신청 데이터는 사이트와 별도 저장소에 있어 사이트 장애로 사라지지 않습니다.

사이트를 고쳤는데 뭔가 깨진 것 같아요 / 깨졌는지 확인하고 싶어요

코드를 GitHub에 올릴 때마다 자동 점검(QA)이 약 2분간 돌아갑니다. GitHub 저장소 커밋 목록에서 커밋 옆 ✓(초록)이면 이상 없음, ✗(빨강)이면 문제가 있는 겁니다. ✗를 누르면 어느 검사가 왜 실패했는지 나옵니다 — 개발 담당에게 그 화면을 전달하세요.

자동 점검이 보는 것: 18개 페이지 렌더링 오류, 레이아웃 깨짐, 메뉴·링크·홈 구성, 공개 키로 데이터 접근 차단 여부, CSS 빌드 누락. 실제 예약을 만들어 보는 검사는 자동으로 돌지 않으므로(테스트 데이터가 쌓임) 큰 변경 후에는 개발 담당이 수동으로 한 번 더 돌립니다. 자동 점검 실패가 사이트 배포를 막지는 않습니다.
