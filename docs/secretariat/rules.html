운영 규칙

시스템이 자동으로 강제하는 규칙입니다. 사무국이 수동으로 지킬 필요는 없고, 문의가 왔을 때 설명할 수 있으면 됩니다.

항목규칙
확정 방식승인 절차 없이 신청 즉시 자동 확정
밋업 시간10:00~17:30, 30분 단위 16슬롯 중 점심 12:00·12:30 제외 14슬롯 × 기관 23곳 = 322석
슬롯 중복같은 기관·같은 시간은 한 건만. 두 사람이 동시에 눌러도 한 명만 성공
여러 기관 예약한 담당자가 여러 상담기관을 예약할 수 있습니다(건수 제한 없음). 막히는 것은 같은 시간에 두 곳, 같은 기관 두 번뿐
밋업 마감9월 15일(화) 자정까지 예약·취소 가능. 이후엔 사무국 대신 취소만
참가신청 마감9월 16일(수) 18:00(행사 종료)까지. 당일 현장 방문자도 모바일로 신청 가능. 정원 없음
참가신청 중복같은 연락처로 두 번 신청 불가
예약번호JGCF-2026-XXXXXX 난수 6자리(순번 아님). 조회·취소에는 번호 + 담당자 연락처가 모두 필요
참가번호JGCF-ATTEND-XXXXXX
소개서 첨부PDF, 20MB 이하. 사무국과 해당 기관만 열람
연락처 형식숫자 9~11자리(하이픈·공백 무관)
개인정보 보유행사 종료 후 1년(2027-09-16)까지. 상담기관 제공분은 행사 종료 즉시 파기

#담당자 식별

"같은 담당자"는 메일 또는 연락처가 일치하는 경우입니다. 같은 회사의 다른 담당자는 별개로 취급됩니다(사업자번호를 받지 않으므로 회사 단위 제한은 없습니다).

#이어서 예약하기

예약 완료 화면의 **"다른 기관도 예약하기"**를 누르면 기업명·담당자·연락처·메일·상담 내용이 채워진 채 예약 페이지로 가고, 회사 소개서는 방금 올린 파일을 그대로 씁니다. 기관과 시간만 고르면 됩니다.
