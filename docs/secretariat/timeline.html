운영 타임라인

모집 오픈 전부터 행사 종료 후까지 사무국이 할 일입니다.

#모집 오픈 전

  • 관리자 화면에 테스트 데이터가 남아 있지 않은지 확인 (밋업 예약·참가신청 탭이 비어 있어야 함)

  • 사무국 계정 2개로 로그인되는지 확인

  • 상담기관 20곳에 계정 개별 전달 (계정 안내 문구)

  • Supabase Storage의 테스트 PDF 삭제 (데이터 운영)

#모집 기간

  • 현황 탭으로 예약률·추이를, 기관별 현황의 점유 격자로 빈 기관·빈 시간대를 파악 → 필요하면 홍보 조정

  • 문의 대응: 문제 상황 대응

#9/15 (화) 자정

  • 밋업 예약·취소 자동 마감. 이후 신청자는 사이트에서 "접수 마감" 안내를 봅니다

  • 기관별 현황 CSV를 내려받아 최종 명단을 상담기관에 일괄 안내 (기관은 자기 화면에서 보거나 인쇄해 부스에 둘 수 있음)

#9/16 (수) 당일

  • 접수 데스크에서 QR로 출석 체크 (행사 당일)

  • 당일 취소·변경 요청은 사무국이 관리자 화면에서 대신 취소

  • 참가신청은 18:00까지 열려 있음 — 현장 방문자에게 /register QR 안내

#행사 종료 후

  • 상담기관에 제공 자료 파기 요청 (방침에 "행사 종료 즉시 파기"로 명시됨)

  • 출석률 보고: 밋업·참가 CSV의 출석 열

  • 2027-09-16 보유기간 만료 시 Supabase 프로젝트 삭제로 전체 파기
