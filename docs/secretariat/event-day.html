사무국 가이드

행사 당일

접수 데스크에서 QR로 출석을 처리하고, 미도착자를 기관에 알리고, 당일 변경 요청을 처리하는 방법입니다.

#준비물

  • 관리자 화면에 로그인된 폰 또는 태블릿 (접수 데스크용). 노트북도 됩니다.

  • 인쇄한 출석 명단(선택) — 밋업 예약 탭 → 인쇄

  • 현장 방문자 참가신청용 /register QR (참가신청은 18:00까지 열려 있습니다)

#출석 체크 — QR (권장)

신청자의 완료 화면(또는 예약 조회 화면)에 체크인 QR이 있습니다. 캡처본도 됩니다.

  1. 직원이 폰 기본 카메라로 QR을 찍는다별도 앱 없이 됩니다 (iPhone·Android 모두)

  2. 관리자 화면이 그 사람 행만 보이는 상태로 열린다처음 한 번만 로그인. 예약번호면 밋업 탭, 참가번호면 참가신청 탭이 자동 선택됩니다

  3. 출석 버튼을 누른다초록색 "출석 ✓"로 바뀌고 시각이 기록됩니다

QR의 내용

QR은 관리자 주소?q=번호 입니다. 검색어만 채울 뿐 인증을 우회하지 않으므로, 로그인하지 않은 사람이 찍으면 로그인 화면만 보입니다.

#출석 체크 — 수동

QR이 없으면 관리자 화면에서 이름이나 연락처로 검색한 뒤 그 행의 출석을 누릅니다. 잘못 눌렀으면 한 번 더 누르면 해제됩니다.

#미도착자 알리기

밋업 예약 탭 상태 필터에서 미도착을 고르면 확정인데 아직 안 온 사람만 남습니다. 상담 시간 직전에 해당 기관에 "아직 안 오셨다"고 알릴 때 씁니다. 상담기관 화면에도 자기 예약 건의 출석/미도착이 보이므로 기관이 스스로 확인할 수도 있습니다.

#당일 변경·취소 요청

  • 마감이 지났으므로 신청자는 사이트에서 취소할 수 없습니다. 사무국이 관리자 화면에서 대신 취소합니다.

  • 새 예약은 누구도 만들 수 없습니다. 변경이 꼭 필요하면 해당 상담기관과 직접 조율합니다.

#현황 보기

현황 탭의 행사 당일 출석 타일에서 밋업·참가 출석 인원이 집계됩니다(새로고침 필요). 행사 후 출석률 보고는 CSV의 출석 열을 그대로 쓰면 됩니다.
