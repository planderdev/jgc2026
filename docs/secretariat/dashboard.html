관리자 화면

/admin의 탭 4개와 검색·필터·CSV·인쇄·대신 취소 사용법입니다.

#탭 구성

탭내용할 수 있는 것
현황모집 상황 요약예약률(확정/280), 참가신청 구분별 수, 오늘 신규, 마감 D-day, 행사 당일 출석, 예약 없는 기관 수, 시간대별 점유 막대, 최근 7일 추이
밋업 예약전체 예약(확정·취소 포함)상담기관·상태 필터(확정/취소/출석 완료/미도착), 검색(기업·담당자·연락처·번호), 소개서 PDF 열기, 건별 취소, 출석 체크
행사 참가신청전체 참가신청검색(이름·소속·연락처·번호), 출석 체크
기관별 현황상담기관 20곳의 예약률·확정·취소·확정 시간대 + 시간대 점유 격자(기관 × 시간)빈 기관·빈 시간대 파악, 격자 칸에 마우스를 올리면 신청 기업 표시

숫자는 새로고침으로 갱신

화면은 자동으로 갱신되지 않습니다. 신청이 들어오는 중에 보고 있다면 새로고침 버튼을 한 번씩 누르세요.

#검색과 필터

  • 검색창은 번호·기업명·담당자·연락처를 한 번에 찾습니다. 연락처는 하이픈 유무와 관계없이 찾습니다.

  • 밋업 예약 탭의 상태 필터: 전체 / 예약 확정 / 예약 취소 / 출석 완료 / 미도착(확정인데 출석 전)

  • 필터·검색을 건 상태가 CSV와 인쇄에 그대로 적용됩니다.

#CSV 내려받기

각 탭 우측의 CSV 내려받기를 누르면 현재 보이는 목록이 파일로 내려옵니다. 엑셀에서 바로 열리며 한글이 깨지지 않습니다. 밋업·참가 CSV에는 출석 여부·출석 시각 열이 포함됩니다.

#인쇄

각 탭 우측의 인쇄를 누르면 버튼·검색창 없이 표만 A4 가로로 나옵니다. 머리글에 제목·건수·출력 시각이 찍힙니다. 기관별 현황은 1쪽 예약률 표, 2쪽 시간대 격자입니다. 폰·태블릿에서도 표로 인쇄됩니다.

#예약을 대신 취소하기

신청자가 전화로 취소를 요청했거나 예약번호를 잃어버린 경우, 밋업 예약 탭에서 해당 행의 취소를 누르고 확인합니다.

  • 취소 즉시 그 시간대가 다른 신청자에게 다시 열립니다.

  • 사무국의 취소는 마감(9/15 자정)과 무관하게 언제든 가능합니다.

  • 취소 사유는 기록되지 않으니 필요하면 별도 메모를 남기세요.

#좁은 화면에서

900px 이하(태블릿·폰)에서는 표 대신 카드 목록으로 보입니다. 시간·상태·출석 버튼이 첫 줄에 있고, 전화번호는 탭하면 바로 걸립니다. 접수 데스크에서 폰으로 쓰기 위한 배치입니다.
