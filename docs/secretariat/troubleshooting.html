사무국 가이드

문제 상황 대응

문의가 들어왔을 때 바로 찾아보는 답변 모음입니다.

#신청자가 예약번호를 잃어버렸어요

관리자 화면 밋업 예약 탭에서 담당자 이름이나 연락처로 검색해 예약번호를 알려주세요. 본인 확인은 신청 시 입력한 연락처로 합니다. 신청자 본인도 예약번호 하나만 알면 조회 화면에서 "같은 연락처의 다른 예약"을 모두 볼 수 있습니다.

#신청자가 전화로 취소해 달래요

마감 전이면 본인이 /meetup/confirm 에서 직접 취소할 수 있다고 안내하고, 어렵다고 하면 관리자 화면에서 대신 취소하세요. 마감 후에는 사무국만 취소할 수 있습니다.

#"이미 예약하셨습니다" / "같은 시간에 이미 다른 상담이"라고 떠요

같은 담당자(메일 또는 연락처 기준)가 같은 기관을 또 예약하거나, 같은 시간에 다른 기관을 예약하려는 경우입니다. 다른 기관·다른 시간을 고르면 됩니다. 한 담당자가 여러 기관을 예약하는 것 자체는 허용됩니다.

#원하는 시간이 마감이래요 / 방금 마감됐다고 떠요

그 기관·시간에 이미 확정 예약이 있는 겁니다. 시스템이 중복을 막은 것이니 정상입니다. 기관별 현황 탭에서 빈 시간대를 바로 확인해 안내하세요.

#마감 후에 예약을 바꿔 달래요

마감(9/15 자정) 후 신청자는 사이트에서 취소할 수 없습니다. 사무국이 대신 취소할 수는 있으나 새 예약은 누구도 만들 수 없습니다. 변경이 꼭 필요하면 해당 상담기관과 직접 조율해 주세요.

#첨부파일이 안 올라간대요

PDF만, 3페이지 이내, 20MB 이하만 됩니다. 화면에서 형식·용량을 먼저 검사해 이유를 칸 아래에 표시하므로, 그 문구를 확인해 달라고 하세요. 페이지가 많으면 필요한 내용만 3페이지 이내로 줄이고, 20MB가 넘으면 PDF를 압축(이미지 해상도 낮추기)해 다시 올리도록 안내합니다.

#상담기관이 비밀번호를 잊었어요

시작하기 › 비밀번호를 잊었을 때 절차대로 Supabase 대시보드에서 새 비밀번호를 지정해 전달하세요. 재설정 메일은 가지 않습니다.

#상담기관이 "내 화면에 예약이 안 보여요"라고 해요

기관 화면에는 확정 상태의 예약만 보입니다. 관리자 화면 밋업 예약 탭에서 그 기관으로 필터해 확정 건이 있는지 확인하세요. 신청자가 취소했으면 사라지는 게 맞습니다. 확정 건이 있는데도 안 보인다면 다른 기관 계정으로 로그인한 것일 수 있습니다 — 화면 상단의 기관명을 확인하세요.

#사이트가 안 열려요

먼저 다른 기기나 네트워크에서도 같은지 확인하세요. 사무국 쪽 네트워크 문제인 경우가 많습니다. 사이트 자체 장애면 개발 담당에게 연락하세요. 이미 들어온 예약·신청 데이터는 사이트와 별도 저장소(Supabase)에 있어 사이트 장애로 사라지지 않습니다.

#사이트를 고쳤는데 깨진 것 같아요

코드를 GitHub에 올릴 때마다 자동 점검이 약 2분간 돌아갑니다. 커밋 옆 ✓(초록) 이면 이상 없음, ✗(빨강) 이면 문제가 있는 겁니다. ✗를 누르면 어느 검사가 왜 실패했는지 나옵니다 — 개발 담당에게 그 화면을 전달하세요. 자세한 내용은 회귀 테스트·자동 점검.

#신청 내역을 한꺼번에 지우고 싶어요 (테스트 데이터 등)

관리자 화면에는 삭제 기능이 없습니다(실수 방지). 데이터 운영 절차대로 개발 담당이 SQL로 정리합니다. 실제 모집 데이터는 보유기간 전에 지우지 마세요.
