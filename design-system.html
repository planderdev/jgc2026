Design System

색상, 타이포그래피, 간격, 반경, 그림자, 기본 컴포넌트를 한 페이지에서 점검할 수 있는 내부용 레퍼런스입니다.

Typeface SUIT Variable

한국어 본문과 UI에 맞춘 단일 산세리프

Max Weight 800

900은 사용하지 않고 black 토큰도 800으로 제한

Spacing 8px Grid

8px 단위 토큰으로 섹션과 컴포넌트 리듬 관리

Radius 8px Base

카드와 입력 요소는 작고 단정한 반경 사용
