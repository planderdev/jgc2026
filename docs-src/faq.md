---

## 비밀번호를 어디서 볼 수 있나요?

운영계정 엑셀뿐입니다. Supabase에서도 볼 수 없고 새 값으로 교체만 할 수 있습니다. → [시작하기](/docs/secretariat/getting-started#비밀번호를-잊었을-때)

## 한 회사가 여러 기관과 만나려면 매번 정보를 입력해야 하나요?

아니요. 완료 화면의 "다른 기관도 예약하기"로 정보와 소개서를 그대로 쓰며 이어서 예약합니다. 같은 시간·같은 기관만 막힙니다. → [운영 규칙](/docs/secretariat/rules)

## 마감 후 예약을 바꿔 달라고 하면?

사무국이 대신 취소는 할 수 있지만 새 예약은 만들 수 없습니다. 기관과 직접 조율합니다. → [문제 상황 대응](/docs/secretariat/troubleshooting)

## 당일 출석은 어떻게 처리하나요?

신청자 QR을 폰 카메라로 찍으면 관리자 화면이 그 사람 행으로 열리고 출석 버튼을 누릅니다. → [행사 당일](/docs/secretariat/event-day)

## 영문판에서 예약하면 관리자 화면이 영어로 나오나요?

아니요. DB에는 한국어 기관명이 저장되고 관리자·기관 화면은 한국어 그대로입니다. → [영문판](/docs/tech/i18n)

## 사이트 문구를 고치고 싶어요

개발 담당이 GitHub에서 수정하면 자동 배포됩니다. 한국어 페이지를 고친 뒤에는 영문판 생성 명령을 같이 실행해야 합니다. → [배포·도메인](/docs/tech/deploy)

## 테스트로 넣은 예약은 어떻게 지우나요?

관리자 화면에선 못 지웁니다. Supabase SQL Editor에서 정리 SQL을 실행합니다. → [데이터 운영](/docs/tech/data)

## 백업은 되나요?

자동 백업이 없습니다. 모집 기간 중 주기적으로 CSV를 내려받아 보관하세요. → [데이터 운영](/docs/tech/data#백업)

## 첨부가 안 올라간대요

PDF, 3페이지 이내, 20MB 이하만 됩니다. 화면이 이유를 칸 아래에 표시합니다. → [문제 상황 대응](/docs/secretariat/troubleshooting#첨부파일이-안-올라간대요)
