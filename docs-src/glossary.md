title: 용어집
description: 화면과 이 가이드에 나오는 말의 뜻입니다.
---

| 용어 | 뜻 |
| --- | --- |
| **비즈니스 밋업(비즈밋업)** | 신청 기업이 AC·VC·기관과 30분 단위로 만나는 1:1 상담 프로그램 |
| **상담기관** | 밋업에서 상담을 제공하는 AC·VC·기관 20곳. 각각 계정이 있음 |
| **슬롯** | 기관 하나의 30분 상담 시간 한 칸. 기관당 14슬롯, 총 280석 |
| **예약번호** | `JGCF-2026-XXXXXX`. 밋업 예약 식별 번호. 조회·취소에 연락처와 함께 필요 |
| **신청번호 / 참가번호** | `JGCF-ATTEND-XXXXXX`. 행사 참가신청 식별 번호 |
| **담당자** | 예약 시 입력한 사람. 메일 또는 연락처가 같으면 같은 담당자로 봄 |
| **확정 / 취소** | 예약 상태. 신청 즉시 확정이며 취소하면 슬롯이 다시 열림 |
| **마감** | 밋업 예약·취소는 9/15 자정, 참가신청은 9/16 18:00 |
| **미도착** | 확정 예약인데 아직 출석 체크가 안 된 상태(관리자 필터) |
| **체크인 QR** | 완료·조회 화면의 QR. 폰 카메라로 찍으면 관리자 화면이 그 번호로 열림 |
| **출석** | 당일 접수 데스크에서 누르는 버튼. 시각이 기록되고 기관 화면에도 표시 |
| **기관별 현황** | 관리자 탭. 20기관 예약률 표 + 기관×시간 점유 격자 |
| **사무국 계정 / 기관 계정** | 전체를 보는 계정 2개 / 자기 기관만 보는 계정 20개 |
| **운영계정 엑셀** | 모든 계정의 이메일·비밀번호가 있는 유일한 파일(JGCF2026-운영계정.xlsx) |
| **Supabase** | 예약·신청 데이터와 계정이 저장된 서비스(서울 리전) |
| **Vercel** | 사이트 호스팅. GitHub 푸시로 자동 배포 |
| **자동 점검(QA)** | 푸시마다 도는 회귀 테스트. 커밋 옆 ✓/✗ |
| **영문판** | /en/ 아래 페이지. 한국어 원본에서 생성되고 사전으로 번역 |
