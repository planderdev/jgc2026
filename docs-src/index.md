행사 사이트는 **행사 안내 · 참가신청 · 비즈니스 밋업 예약**을 한곳에서 처리합니다. 신청은 즉시 확정되고, 사무국은 관리자 화면에서 전체 현황을 보며, 상담기관은 자기 일정만 봅니다. 이 가이드는 역할별로 나뉘어 있습니다 — 처음이라면 자기 역할의 첫 문서부터 읽으세요.

<li><a href="/docs/partner/overview"><strong>상담기관 가이드</strong><span>내 상담 일정 확인, 소개서 열람, 부스 인쇄</span></a></li>
