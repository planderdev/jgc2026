## 계정 종류

| 계정 | 개수 | 볼 수 있는 것 | 할 수 있는 것 |
| --- | --- | --- | --- |
| **사무국** | 2 | 전체 예약·참가신청 | 검색·필터, CSV·인쇄, 대신 취소, 출석 체크, 소개서 열람 |
| **상담기관** | 22 | 자기 기관의 확정 예약만 | 읽기, CSV·인쇄, 소개서 열람 |

두 계정 모두 같은 주소 **/admin** 으로 로그인하고, 계정에 따라 화면이 달라집니다. 상담기관 계정은 `기관아이디@2026jejugcf.com` 형식입니다.

:::warn 자격증명의 위치
비밀번호는 **운영계정 엑셀(JGCF2026-운영계정.xlsx)** 에만 있습니다. 시스템 어디에서도 평문을 다시 볼 수 없습니다(해시로만 저장). 파일을 안전한 곳에 보관하세요.
:::

## 처음 로그인

1. **주소 열기** — https://2026jejugcf.com/admin
2. **엑셀의 값 입력** — "사무국 계정" 시트의 이메일과 비밀번호. 난수라 한 글자만 달라도 실패하므로 셀 값을 그대로 복사하세요.
3. **현황 탭 확인** — 로그인되면 현황 탭이 먼저 열립니다. 모집 전에는 예약 0 · 참가신청 0이어야 정상입니다.

## 상담기관에 계정 전달

각 기관에는 **그 기관의 행만** 보냅니다. 엑셀을 통째로 보내면 한 기관이 다른 21곳 계정으로 들어가 남의 신청 기업 연락처와 소개서를 볼 수 있습니다. 메일 본문은 [계정 안내 문구](/docs/partner/notice-template)를 쓰세요.

## 비밀번호를 잊었을 때

계정 주소(`기관아이디@2026jejugcf.com`)는 로그인용 아이디일 뿐 **실제로 메일을 받는 주소가 아닙니다.** 그래서 재설정 메일이 가지 않습니다 — 사무국이 직접 새 비밀번호를 지정해 전달합니다.

1. **Supabase 대시보드** — Authentication → Users ([바로가기](https://supabase.com/dashboard/project/ahabmxxenajosbdkzull/auth/users))
2. **계정 검색 → Reset password** — 새 비밀번호 입력 후 저장
3. **전달·기록** — 담당자에게 전달하고 운영계정 엑셀도 갱신

:::info 왜 비밀번호를 볼 수 없나요
Supabase를 포함한 모든 제대로 된 인증 시스템은 비밀번호를 복구 불가능한 해시로만 저장합니다. 할 수 있는 것은 "새 값으로 교체"뿐입니다.
:::
