## 예약 4단계

1. **상담기관 선택** — 22곳 중 한 곳. 각 기관의 상담 분야가 카드에 적혀 있습니다
2. **시간 선택** — 10:00~17:00, 상담 25분(30분 간격 시작). 이미 예약된 시간은 "마감", 점심은 "점심시간"으로 비활성
3. **신청 기업 정보** — 기업명·담당자·연락처·메일·회사 소개서 PDF(20MB 이하)·상담 내용·동의
4. **확인 → 예약 완료** — 즉시 확정. **예약번호**(JGCF-2026-XXXXXX), 복사 버튼, **체크인 QR**이 나옵니다

완료 화면의 **"다른 기관도 예약하기"**를 누르면 정보가 채워진 채 1단계로 돌아가고 소개서도 재사용됩니다.

## 서버가 거부하는 경우

| 메시지 | 뜻 | 안내 |
| --- | --- | --- |
| 방금 다른 참가자가 이 시간대를 예약했습니다 | 기관·시간 선점 | 다른 시간 선택(2단계로 돌아감) |
| 같은 시간에 이미 다른 상담이 예약되어 있습니다 | 같은 담당자, 같은 시간 | 다른 시간 선택 |
| 이 상담기관은 이미 예약하셨습니다 | 같은 담당자, 같은 기관 | 다른 기관 선택(1단계로 돌아감) |
| 밋업 예약 접수가 마감되었습니다 | 9/15 자정 이후 | 사무국 문의 |

## 조회·취소 (/meetup/confirm)

- **예약번호 + 담당자 연락처**가 모두 맞아야 내용이 보입니다
- 조회되면 같은 연락처의 **다른 예약 목록**도 함께 보여 하나만 기억해도 전부 찾을 수 있습니다
- 마감 전 확정 건에는 **예약 취소** 버튼이 있습니다(확인 창 한 번). 취소하면 그 시간대가 즉시 다른 신청자에게 열립니다
- 마감 후에는 취소 버튼 대신 사무국 연락처 안내가 나옵니다
- 체크인 QR도 여기서 다시 볼 수 있습니다
