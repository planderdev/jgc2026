## 흐름

1. **구분 선택** — 기업 / 일반 / 학생. 구분에 따라 기업명·담당자, 이름, 학교명·학생 이름 칸이 바뀝니다
2. **연락처·메일 주소 입력, 동의 체크** — 연락처는 숫자 9~11자리, 메일은 형식 검사
3. **신청 완료** — 즉시 접수되고 **신청번호**(JGCF-ATTEND-XXXXXX)와 **체크인 QR**이 나옵니다. 입력한 주소로 접수 안내 메일이 갑니다
4. **조회·취소** — `/register-confirm`에서 신청번호와 연락처로 상태를 확인하고, 행사 종료 전이면 직접 취소할 수 있습니다

완료 화면은 신청 직후에만 보이므로 "캡처해 두세요"라고 안내합니다. 잃어버리면 안내 메일의 신청번호를 확인하거나, 당일 데스크에서 이름·연락처로 찾습니다.

## 규칙

- 신청·취소 마감: 행사 당일 **9월 16일 18:00**. 현장 방문자도 폰으로 바로 신청할 수 있습니다
- 같은 연락처로 확정 신청은 한 번만 가능 ("이미 참가신청이 접수된 연락처입니다"). 취소한 뒤에는 다시 신청할 수 있습니다
- 정원 없음, 승인 절차 없음
- 메일 주소는 접수 안내 메일을 받는 주소입니다. 오타가 나면 메일만 가지 않고 접수는 그대로 유효합니다 — 사무국이 관리자 화면에서 확인할 수 있습니다

## 입력 검증

빈 칸이나 형식 오류가 있으면 화면 가운데 알림과 함께 **문제 칸이 빨갛게** 표시되고 이유가 칸 아래에 나옵니다. 여러 칸이면 "입력하지 않은 항목이 N개 있습니다". 영문판(/en/register)도 같은 폼입니다.
